# UnionBot

Установка: `npm install`. Заполните `.env` по примеру `.env.example`, затем запустите `npm start`.

Для разработки используйте `npm run dev`. Изменения исходников перезапускают бота, а сохранение статуса ивента и временные файлы тестов исключены из наблюдения в `nodemon.json`.

Бот проверяет игровой сервер раз в минуту; TAB также запрашивает актуальные данные. Статус `offline` появляется после трёх последовательных проверок без ответа сервера, в том числе при запуске. При единичных сбоях название канала сохраняется, а любой ответ сервера сбрасывает счётчик недоступности. Ошибки или расхождения в списке игроков не считаются отключением, если сервер ответил на запрос информации.

Discord может отложить переименование канала из-за ограничения частоты изменений. До указанного в логах срока название может отставать от данных TAB; после ожидания бот отправляет последнее актуальное название.

## Отметка ивента

В `.env` укажите ID ролей Discord, которым разрешено менять отметку:

```dotenv
EVENT_MANAGER_ROLE_IDS=123456789012345678,234567890123456789
```

Достаточно одной из указанных ролей. Если список пуст, команды не меняют статус.
После изменения `.env` перезапустите бота.

- `/server close` отправляет новое уведомление об активности: «Изменения активности на сервере», строку «🔒 Сервер закрыт на ивент», текущий онлайн и карту в каждый канал из `CHANNEL_IDS`.
- `/server open` отправляет новое уведомление «🔓 Сервер доступен по текущему паролю» с текущим онлайном и картой в эти же каналы.

Каждый вызов команды отправляет отдельное сообщение с кнопкой TAB. Через неё можно посмотреть актуальный онлайн.
При `/server close`, `/server open` и автоматическом открытии бот запрашивает актуальные данные сервера. Если сервер не отвечает или данные не согласованы, в полях онлайна и карты будет «Нет данных», а запрошенный статус всё равно сохранится. Уведомление об открытии содержит онлайн в формате «игроков/мест» и карту.
Пока ивент активен, новые уведомления об активности содержат строку «🔒 Сервер закрыт на ивент». После `/server open` они отправляются без этой строки.
Это информационная отметка: команды не меняют доступ к игровому серверу. Подтверждение команды видит только её автор.

Во время ивента название каналов имеет вид `🔒・union・2⁄26・карта`. При ручном или автоматическом открытии замок сменяется обычным индикатором онлайна. Счётчик игроков и карта продолжают обновляться во время ивента.

Команда `/server` регистрируется при запуске в Discord-серверах настроенных каналов. После успешной регистрации бот удаляет прежнюю slash-команду `/event`; остальные команды сохраняются.
Для отправки уведомлений боту нужен доступ к каналу, отправке сообщений и встраиванию ссылок (Embed Links).

Состояние ивента хранится в `event-status.json` рядом с `index.ts` в корне проекта и восстанавливается после перезапуска. Сохраните этот файл при переносе бота. Статус общий для одного игрового сервера во всех настроенных каналах.

Через четыре часа после `/server close` бот автоматически снимает статус ивента и отправляет обычное объявление об открытии сервера. Ручной `/server open` отменяет таймер, а повторный `/server close` начинает новый отсчёт на четыре часа. Срок сохраняется при перезапуске; если он истёк, пока бот был выключен, объявление отправится после подключения к Discord. Для активного ивента, сохранённого старой версией без срока, первый отсчёт начнётся после запуска обновлённого бота.

Проверки: `npm test` и `npm run typecheck`.
